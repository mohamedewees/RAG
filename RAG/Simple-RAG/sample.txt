Retrieval-Augmented Generation, or RAG, is a technique that combines a search step with a text generation step. Instead of relying only on what a language model learned during training, RAG lets the model look things up first, then answer using what it found. This makes answers more accurate and lets the system use information the model was never trained on, like your own documents. The basic pipeline has a few stages: parsing documents into plain text, splitting that text into chunks, turning chunks into embeddings, storing those embeddings in a vector database, and finally retrieving the most relevant chunks to answer a question.
